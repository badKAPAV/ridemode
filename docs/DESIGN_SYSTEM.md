# Design system contract

M1 foundation part 1 implements `RideTheme`, `RideTypography`, `RideUiTokens` and reusable controls in `core/ui`. [Proposed tokens](../config/design-tokens.json) remain illustrative; Kotlin Compose tokens are canonical until JSON-to-Kotlin generation/parity validation exists (ADR-001). PRD constraints take precedence over proposed values.

- Theme: `MaterialExpressiveTheme` from Material 3 `1.5.0-alpha18`; wallpaper dynamic light/dark colors on API 31+, Expressive light/dark defaults on API 24–30. The proposed normal JSON palette does not drive runtime colors. OLED black remains planned for saver work.
- System bars: `MainActivity` follows the system light/dark setting for status and navigation bar icon contrast. Pixel 8a light-palette screenshot verified dark status icons against the pale dynamic background; physical dark-palette verification remains pending.
- Font and icons: bundled Roboto Flex; title styles use width axis 125 on API 26+, body styles use normal width, and title width falls back to normal on API 24–25. Phosphor icon pack supplies UI vectors. Font license is in `docs/licenses/ROBOTO_FLEX_OFL.txt`.
- Shared controls: `RideActionButton` has 64 dp minimum height; `RideSurface` uses expressive theme surfaces; `RideLoadingIndicator` uses Material 3's morphing shape loader and an accessibility label. These are foundation components, not registered dashboard widget types.

- Typography: clock 64–120 sp by widget size; primary labels 20–28 sp; secondary 14–18 sp, honor font scale. Proposed scale in JSON is not a cap.
- Color: high-contrast dark ride UI, true `#000000` OLED idle, restrained accent and color-independent priority markers. Keep navigation freshness visible.
- Spacing: 12–16 dp gaps around ride controls. Grid is 12 columns; row height is configurable. Rounded corners and icons are proposed values, not a shipped asset system.
- Touch: minimum 56 dp, primary actions target 64–80 dp including hit area. Pressed state and optional short haptic. Avoid tiny dismiss icons and blocking ride dialogs except confirmations.
- Accessibility: TalkBack labels/actions, font scaling, contrast checks, reduced motion option, solid numeral fallback when outline loses readability. Test sunlight, gloves and vibration while stationary.
- Landscape: Home/Settings remain system-oriented; Start Ride opens a dedicated sensor-landscape activity with a dark preview and persistent rail. The rail shows End Ride, page status, and readable noninteractive Maps/assistant placeholders. Android may keep system bars visible for an active call; a no-call immersive check remains pending. Editor, safe-inset hardening, resizing and process-death recovery remain planned.
- OLED: single layout tree with NORMAL/OLED_IDLE presentation state. Top-level interceptor consumes first touch to wake; underlying SOS/media controls receive no event. Use monotonic idle timer and lifecycle awareness. Outline-only large numerals have solid accessibility fallback; optional window brightness reduction never changes global brightness.

Implemented foundation screens: Home links to Settings, Getting Started and Access and Privacy and starts Ride. Settings explains upcoming display and notification choices without active toggles. Getting Started presents preparation and safety guidance. Access and Privacy explains future grants without asking for them. `RideScreen` supplies scrolling/insets, title and accessible back control; `RideInfoCard` uses the shared expressive surface and button. Ride has three fixed, labeled preview pages and a rail; functional settings, editor, persisted pages, widgets, saver, notifications, calls and assistant execution remain planned.

Implementation references: [Material 3 Expressive theme](https://developer.android.com/reference/kotlin/androidx/compose/material3/MaterialExpressiveTheme.composable), [Material 3 releases](https://developer.android.com/jetpack/androidx/releases/compose-material3), [Compose variable fonts](https://developer.android.com/develop/ui/compose/text/fonts), [Roboto Flex source](https://github.com/google/fonts/tree/main/ofl/robotoflex), [Phosphor Compose port](https://github.com/adamglin0/compose-phosphor-icon).
